- [x] Manifest, package, lockfile, and versions map agree on `0.6.0`.
- [x] `npm test` passes.
- [x] `npm run typecheck` passes.
- [x] `npm run build` produces `main.js`.
- [x] Installed build matches the source build.
- [x] Gate 0 Canvas round trip passed.
- [x] Existing Canvas read-only sample completed.
- [x] Release ZIP and SHA-256 checksum generated locally.
- [x] Add the MIT public-source license.
- [x] Create the dedicated public GitHub repository.
- [ ] Publish and verify the `v0.6.0` GitHub release.
- [ ] Verify BRAT installation from that GitHub repository.
- [ ] Perform physical iOS and Android device checks.
- [ ] Decide whether to submit to the Obsidian community plugin directory.
